# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## 位置情報メニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- ダイヤモンド富士が見える場所をわかりやすく伝えるために、辻ラインを表示するが、それを計算すための基本情報の観測点/目的点の緯度/経度/標高を入力できるようにする。
### 概要:
- 0段目:
  - 1. 「位置情報」ラベル:
    - 太字、左寄せ
  - 2. 「▲」ラベル:
    - 右寄せ
  - 共通事項:
    - タップすると、位置情報メニューが開閉する。
    - 背景グレー、不透明
    - 初期状態:開いている
- 1列目:
  - 1段目:
    - 3. 「GPS」ボタン:
      - 現在地を取得すると、ラジオボタンで選択された方の観測点/目的点に緯度/経度/標高が入力される。
      - スマホで現在地を取得できるようにする。
  - 2段目:
    - 4. 「Hom(e)」ボタン:ラベル「Hom」
      - 観測点を登録しておくためのもの。観測点が空白で、リセットできる。
      - ローカルストレージに保存して、観測点情報(緯度経度標高)を呼び出せるようにする。
      - 押したらどうなるか分かるメッセージをtitle属性でツールチップで表示する。
  - 3段目:
    - 5. 「推(し)山」ボタン:ラベル「推山」
      - 目的点を登録しておくためのもの。目的点が空白で、リセットできる。
      - ローカルストレージに保存して、目的点情報(緯度経度標高)を呼び出せるようにする。
      - 押したらどうなるか分かるメッセージをtitle属性でツールチップで表示する。
  - 4段目:
    - 6. 「URL取得」ボタン:ラベル「URL」
      - 宙の辻のURLにクエリストリングを渡して、開くURLを取得する。
        - 現在と同じ画面が開けるように、位置情報、日時情報、表示天体をURLのクエリストリングに設定して、URLをクリップボードのコピーする。
        - ①日時固定(年月日、時間)の場合のURLと、②日時半固定(年を「0000」とした時に、アクセスした時の年に変換し、月日と時間は、URLを取得する時の日時情報の設定に従う)と、③URLにアクセスした時の現在日時のアクセス日時を開く場合のURLを、観測点/目的点の地名検索ダイアログ画面のように、ポップアップで選択できるようにする。
            - ①位置情報の日時を確認する「日時固定(YYYY年MM月DD日hh:mm)」ラベルと、②「日時半固定(アクセス年のMM月DD日hh:mm)」ラベルと、③「アクセス日時」ラベル、の3つと、それぞれにコピーできるボタンがある。
            - URLをクリップボードにコピーすると、次の確認メッセージ「現在の状態で宙の辻を開くURLをクリップボードにコピーしました。」（window.alertで、OK）が表示される。
  - 5段目:
    - 7. 「辻ライン365」トグルボタン:ラベル「辻」
      - 辻ラインを365日分同時に描画するトグルボタン。
        - 辻ラインは、ちょうどの破線のみ(前後日の線や時刻文字列は表示しない)を1分間隔版で365日分同時に描画して、トグルボタンで表示・非表示を切り替えられる。
        - 計算処理が重いので、並行・並列・ワーカープールの非同期処理にする。
        - 表示天体分描画する。
        - 表示天体メニューで表示を切り替えた時に、表示・再表示出来るようにする。
        - ツールチップで、「辻ライン365(直近1年の辻ラインを描画します)」を表示する。
        - 初期表示は、常にOFF。
  - 6段目:
    - 8. 「準最高地点移動」ボタン:ラベル「高移」
      - 現在、9.ラジオボタンで選択されている観測点/目的点の近傍の画像ピクセル(256×256)を全て検索して、現在の画像ピクセルから最も近い現在より高い位置の小ピーク(その近傍の中で最高地点とは限らない)に移動する。
      - ①最も近い②現在より高い位置の小ピークの①②の順でピークを判定し、移動する。
      - 現在地点を画面中心に、できる限り画面をズームして、DEM標高タイルで算出する。
- 2列目:
  - 1段目/3段目:
    - 9. ラジオボタン
      - ユーザーが画面をタップした時に、観測点を入力させるか、目的点を入力させるか、切り替えるためのもの。
- 3列目:
  - 1段目:
    - 10. 「観測点:」テキストボックス:
      - 地名、およその住所、緯度/経度から、地図上に観測点を設定する。
      - プレースホルダー:「地名 住所 緯度,経度」
  - 2段目:
    - 11. 「観測点標高:」テキストボックス:
      - 観測点の緯度/経度から標高を設定する。
      - プレースホルダー:「標高 m」
  - 3段目:
    - 12. 「観測点高:」テキストボックス:
      - 観測点の高さを設定する。
      - プレースホルダー:「追加高さ m」
  - 4段目:
    - 13. 「目的点:」テキストボックス:
      - 地名、およその住所、緯度/経度から、地図上に目的点を設定する。
      - プレースホルダー:「地名 住所 緯度,経度」
  - 5段目:
    - 14. 「目的点標高:」テキストボックス:
      - 目的点の緯度/経度から標高を設定する。
      - プレースホルダー:「標高 m」
  - 6段目:
    - 15. 「目的点高:」テキストボックス:
      - 目的点の高さを設定する。
      - プレースホルダー:「追加高さ m」
- 各列共通
  - 7段目:均等に横幅いっぱいで配置
    - 16. 「辻ライン」トグルボタン:ラベル名は、「辻ライン」
      - 辻ラインを表示するためのボタン。
      - 押されている状態の時は、ラベル名を太字で、ボタン色を黄色にする。
      - 初期状態:押されている状態
    - 17. 「全天儀」トグルボタン:ラベル名は、「全天儀」
      - 全天儀を表示するためのボタン。
      - 押されている状態の時は、ラベル名を太字で、ボタン色を黄色にする。
    - 18. 「標高グラフ」トグルボタン:ラベル名は、「標高グラフ」
      - 標高グラフを表示するためのボタン。
      - 押されている状態の時は、ラベル名を太字で、ボタン色を黄色にする。
  - 8段目:均等に横幅いっぱいで配置
    - 19. 「辻検索」トグルボタン:ラベル名は、「辻検索」
      - デッサン`03-tsujisearch.md`を参照。
    - 20. 「辻メッシュ検索」トグルボタン:ラベル名は、「辻メッシュ」
      - デッサン`04-tsujimeshsearch.md`を参照。
    - 21. 「宙の窓」トグルボタン:ラベル名は、「宙の窓」
      - デッサン`05-soranomado.md`を参照。
### 仕様詳細:
- 16. 「辻ライン」トグルボタン:
  - 観測点標高、目的点標高、観測点視高度を利用して、垂直に立てた棒にできる影の長さの計算を応用して、観測点から目的点の方向に天体が重なる位置と時刻を求めて、地図上に図示する。
    - 破線(- - -):当日の辻ライン。5分刻みの●マーカーと時刻を表示。
    - 一点鎖線(-·-·-):天体の視半径（見かけの大きさ）を考慮したエッジライン。天体の縁が目的点に接する位置を示します。
    - 点線(· · ·):前日・翌日の辻ライン。
    - 当日線の窓は「現在の日時に最も近い南中±12時間」とする(前日線・翌日線はその±24時間の窓)。「当日0:00以降で最初の南中」を使うと、月のように南中が毎日約50分遅れる天体で、南中が23時頃→辻時刻が翌未明(例: 5時)の辻が前日窓=点線側に落ちて1日ずれて見えるため。
- 17. 「標高グラフ」トグルボタン:
  - 観測点から目的点までの直線を2000地点をサンプルして標高を取得してグラフ表示する。
    - 画面下3分の1に表示する。
    - 縦軸に標高、横軸に直線距離がわかるようにいくつか中間点を配置する。
    - 国土地理院の標高タイルを利用して、キャッシュを利用できるような形で取得する。しかし、ローカルストレージやappStateには、キャッシュは保存しない。
    - 国土地理院の標高タイル取得は、アルゴリズムで並列化しておく。実運用で、並列度を変更して運用できるようにする。
    - 観測点高と目的点高を考慮したスタート地点からゴール地点までの可視可能かどうかを判断する可視直線を赤色で描画する。
      - グラフ描画終了後、標高の各点が可視直線より全て下かどうかを判断し、可視なら「OK」ポップアップを、不可視なら「NG」ポップアップを表示する。
    - 全天儀とは排他(一方を開くと他方は閉じる)。辻検索結果とは同時表示できる。
- 18. 「全天儀」トグルボタン:
  - 標高グラフとは排他(一方を開くと他方は閉じる)。辻検索結果とは同時表示できる。
  - 標高グラフと同じように、画面下3分の1に表示する。
  - 観測者の位置情報の緯度・経度・標高・高さと日時情報の日時を考慮して、天の川を全天に内側から見ると「天の川の環」が見えるが、その「天の川の環」を地球儀のように外側から俯瞰して見るような3Dの天体儀を表示する。また、実際は、内側から見ているため、内側からも俯瞰して見えるように、「天の川の環」が両面で見えるように、内側からも透けて見えるようにする。
  - 観測者の位置情報、日時情報を移動すると、全天儀の「天の川の環」もそれに合わせて移動する。
  - 表示詳細
    - 東西南北の方位、緯度と経度の線、地平線が分かるように表示する。
    - 初期表示は、毎回、北が上になるようにする。
    - グリッドは、緯度・経度を15°刻みにする。また、地平面は、地平面の中心から15°刻みの放射状の線を引く。
    - 東西南北のマーカーは、北は赤色、東西南は水色、地平面と外側の枠が交わる水平線は緑色、で表示する。
    - 地平線の緑色の線は、太線にする。正面から見える前面は実線で、正面から奥に見える背面は破線で描画する。全天儀を回転しても、常に前面が実線、背面が破線になるように追従する。
    - 地平面と外側の枠が交わる水平線には、北を0°として、30°おきに目盛の数字を入れる。
    - 視点回転は、マウスはドラッグ、スマホは2本指のスクロールで行う(1本指では回転しない)。ホイールでズーム。
    - 表示オブジェクト
      - 表示天体メニューの天体
        - 天の川
          - NASA(https://svs.gsfc.nasa.gov/4851/)からダウンロードした天の川の写真(milkyway-skymap.webp)。
          - 天の川の星や星雲をイメージして分かりやすいように、「天の川の環」に合わせて、天体写真を合成して、天の川を表示する。
            - 天体写真は、NASAなどが公開している著作権を表示すれば無料で使用できるものを使用する。
            - 画面内の右下に、用いた天体写真の著作権表示をする。
          - 天の川銀河の銀河座標の水平面の環をグリッドに白色の太線で環状に表示する。（天の川リングとする。）
          - グリッドの地平面の中心から、銀河の中心座標（いて座付近）に向かって、直線を白色の太線を引く。（天の川方位線とする。）
          - 天の川リングと天の川方位線の交点に赤いマーカーを付ける。
          - 天の川の軌跡
            - 天の川の中心座標からのオフセット点の軌跡を天体色の線で描画する。
            - 軌跡は、オフセット点を0°として、-180°から+180°までを常に描画する。
            - 正面から見える前面は実線で、正面から奥に見える背面は破線で描画する。全天儀を回転しても、常に前面が実線、背面が破線になるように追従する。
          - 「天の川の環」を示す白い線。
          - ①天の川の中心座標を示す赤いマーカーとその方向を示す中心からの白い方位線。
          - ②天の川の中心座標からのオフセット点を示す天体色のマーカーと、その方向を示す中心からの天体色の方位線。
          - 上記①と②が重なる場合は、①を表示して②は表示しない。
          - 全天儀の右側か左側にある表示天体名の名称と、その名称からの引き出し線が、オフセット点を指し示す線。
        - 惑星
          - 惑星の軌跡
            - 惑星の中心座標の軌跡を天体色の線で描画する。
            - 軌跡は、惑星の中心座標を0°として、-180°から+180°までを常に描画する。
            - 正面から見える前面は実線で、正面から奥に見える背面は破線で描画する。全天儀を回転しても、常に前面が実線、背面が破線になるように追従する。
          - 惑星の視半径を反映した天体色のマーカーと、その方向を示す中心からの天体色の方位線。
          - 全天儀の右側か左側にある表示天体名の名称と、その名称からの引き出し線が、表示天体を指し示す線。
        - 恒星
          - 恒星の軌跡
            - 恒星の中心座標の軌跡を天体色の線で描画する。
            - 軌跡は、恒星の中心座標を0°として、-180°から+180°までを常に描画する。
            - 正面から見える前面は実線で、正面から奥に見える背面は破線で描画する。全天儀を回転しても、常に前面が実線、背面が破線になるように追従する。
          - 恒星の位置を反映した天体色のマーカー(+)と、その方向を示す中心からの天体色の方位線。
          - 全天儀の右側か左側にある表示天体名の名称と、その名称からの引き出し線が、表示天体を指し示す線。
      - 星座線
        - NASA(https://svs.gsfc.nasa.gov/4851/)からダウンロードした各星座の星座線(constellation-figures-skymap.webp)の写真を表示/非表示するチェックボックス。
        - 画面内の右下に、用いた天体写真の著作権表示をする。
      - 星座領域
        - NASA(https://svs.gsfc.nasa.gov/4851/)からダウンロードした各星座の星座線(constellation-figures-skymap.webp)の写真を表示/非表示するチェックボックス。
        - 画面内の右下に、用いた天体写真の著作権表示をする。
      - 星座名称
        - 全天儀の両側にある各星座名称と、その星座名称からの引き出し線が、各星座線と各星座領域を指し示す線を表示/非表示にするチェックボックス。
        - 星座名称は全て(88星座)表示する。前面に見える星座だけ引き出し線を引き、背面に隠れている星座は引き出し線を引かない。
        - 両サイドの星座名称をタップ/クリック/マウスオーバーすると、星座名称から引き出し線が黄色と赤色の点滅で分かりやすくハイライト表示され、また、各星座の星座領域は、座標が分かっているので、その星座領域の枠を黄色と赤色の点滅で分かりやすくハイライト表示する。
        - 各星座の星座線は、座標が分かっているので、その星座線を黄色と赤色の点滅で分かりやすくハイライト表示する。
        - 星座名称は、①左上から右下へ50音順で表示、②北極星を天頂+90°として、春分点を0°とした全天儀の座標系で、星座領域の中心点の座標が、天頂+90°から-90°方向に存在する順序で表示、を選択できる。
        - 星座名称は、日本語で。
- 共通機能/デザイン
  - 下部パネルのトグルと地図移動:
    - 全天儀(全天儀)・標高グラフ・宙の窓・辻検索のトグルボタンをオン/オフした時は、観測点が分かりやすいように、画面の「パネルで隠れていない残りの表示領域」の中央へ、観測点が来るように地図を移動(パン)する。
    - パネルは画面下から1/3ずつ積み上がる(全天儀/標高グラフ/宙の窓は排他で下1/3、辻検索はそれらと併用可で最大下2/3が隠れる)。隠れている高さに応じて、可視領域の中央に観測点を配置する。全パネルを閉じた時は画面全体の中央へ戻す。ズーム率は変えずにパンのみ。
    - 地図左上(地図パンボタンの下)に、マーカー中央表示ボタン(⌖)を置く: 位置情報メニューの観測点/目的点切り替えボタンで選択されているマーカーを、可視領域(下部パネルを除く)の中央に表示する(ズームは変えずパンのみ)。
  - テキストボックス:
    - 未入力でフォーカスが外れた場合、元の値を復元する。
    - title属性でテキストボックスの内容をツールチップで表示する。
    - input:type=textは、最大文字数150文字とする。
    - XXS対策で、入力内容をタグエスケープする。
    - フォーム、appState、ローカルストレージで、整合性が取れるようにする。
  - 背景色:
    - 1〜7段目は、背景白で、少し透明で、背景の地図が見える。
