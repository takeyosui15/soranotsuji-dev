# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## 辻メッシュ検索メニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- 精度角距離が◎以内の日時と場所を画素単位で網羅したい場合の検索方法
- 辻検索では、位置が固定で、位置から高い精度の日時を求めるだが、DEM標高タイルの各画素毎に、辻検索をして、◎精度以内の日時を網羅することで、どの位置で高い精度の日時が存在するのかがわかるようになる。
### 概要:
- 機能概要
  - 辻メッシュ検索
    - 観測点付近の9枚のDEM標高タイルの全ての画素の位置で、辻検索をする。
    - 算出対象の天体は、天体リストで表示がオンになっているものを対象とする。
    - 検索結果は、日時順にソートして、スライダーで、順次選択できる。
    - 精度角距離が◎以内の画素には、金色のマーカーを設定し、位置が分かるように表示する。

### 仕様詳細:
- 2. 「辻メッシュ」検索トグルボタン:
  - 機能概要
    - 位置情報から、オフセットありで、リストアップ対象の許容範囲ありで、検索中心からどれくらい離れているかの精度を表示して、最後に精度フィルタでフィルタして、検索期間内で日付と時刻のリストアップをする。
    - 算出対象の天体は、天体リストで表示がオンになっているものを対象とする。
    - 検索結果表示領域にリストとコントロールを表示する。
    - リストは項目別にソート可能。
    - リストの表示項目:
      - 天体ID:アルファベット、数字
      - 天体名:テキスト
      - 精度記号:◎○△-
      - 精度角距離:「0.00000°」
      - 日付:「YYYY年MM月DD日」
      - 曜日:「(和暦)」:月火水木金土日
      - 辻時刻:「hh:mm:ss.ff」(0.01秒表示)
      - 時間帯:「`0時<=x<天文薄明[始]`」等
      - 日の出時刻:「hh:mm:ss」
      - 日の入時刻:「hh:mm:ss」
      - 月の出時刻:「hh:mm:ss」
      - 月の入時刻:「hh:mm:ss」
      - 月齢:「0.0」
      - 月齢アイコン:「🌕」
      - 方位角:「0.0000°」
      - 視高度:「0.0000°」
      - 視半径:「0.000°」
      - 天体方位角差:「+-0.0000°」
        - 天体の方位角から目的点の方位角を引いた差を正負記号をつけて表記する。
        - 目的点より天体が右にある場合は正、左にある場合は負。
      - 天体視高度差:「+-0.0000°」
        - 天体の視高度から目的点の視高度を引いた差を正負記号をつけて表記する。
        - 目的点より天体が上にある場合は正、下にある場合は負。
      - オフセット中心角:「0.0000°」
      - 標高グラフ: 「OK」/「NG」/「-」
    - 月齢、月齢アイコンは、月以外のどの天体の時も、その日付で、その辻時刻の時の月齢と月齢アイコンを表示する。
  - 精度記号
    - ◎: 天体の中心がほぼ目的点に重なる日（誤差±0.125°\[誤差範囲0.25°、およそ視半径以内\]）
    - ◎×2: ◎の2倍精度（誤差±0.0625°\[誤差範囲0.125°\]）
    - ◎×4: ◎の4倍精度（誤差±0.03125°\[誤差範囲0.0625°\]）
    - ◎×8: ◎の8倍精度（誤差±0.015625°\[誤差範囲0.03125°\]）
  - 処理内容の概要:
    - 観測点を中心に含む9枚(初期値)のDEM標高タイルの全ての画素の位置を観測点として、精度フィルタ◎以内で、辻検索をする。
    - 進捗バーを表示する。
    - 算出対象の天体は、天体リストで表示がオンになっているものを対象とする。
    - ワーカープールで、並列並行非同期処理をする。アクティブワーカー数は、CPU数+1にする。
    - 検索結果は、表示天体、日時順にソートする。
    - 結果リストは、全メッシュマーカー(ヒット画素)を日付毎にグルーピングして、その日付での最良精度のデータを日付毎に1行で表示する。
      - 行の辻時刻・精度記号・精度角距離・方位角・視高度は、その日に領域内で最高精度が出る画素(最良画素)の辻時刻と、その時の値(最良画素基準)。
      - 行の辻時刻・精度角距離・方位角・視高度は、0.01秒精細化後の値(優辻マーカーのポップアップと同じ値)。辻時刻は「hh:mm:ss.ff」(0.01秒)で表示する。
      - 検索本体は1秒格子で判定し、辻時刻スライダーは1秒刻み(行選択・ポップアップの行クリック時はサブ秒を保持して表示・再計算に反映し、スライダーの手動操作でサブ秒は0にリセット)。
      - 行の存在条件は、領域内のいずれかの画素で精度フィルタオプションで指定した精度(初期値:◎)以内になる日を行にする。
      - 観測点マーカーは、検索エリアを指定するための基準であり、行の表示値の基準ではない。
    - 精度角距離が◎以内の画素には、マーカー(メッシュマーカー)を設定して、位置が分かるように表示する。
      - メッシュマーカーは、ヒット件数のグラデーションのタイルで描画する: 1件=メッシュマーカー色(スライダーのグレースケール・既定は白)、件数が多いほど金色に近づき、最大件数=最も金色(#FFD700)。既定では白色から金色のグラデーション。0件は無色(対象外)。
      - 最大件数とは、1タイルに含まれる全表示天体での合計件数を他のタイルと比べたときの最大値。
      - 最大件数のタイル(2件以上ある時)は、金色と赤色の斜めの縞模様にする(最多ヒットの場所が一目で分かる)。
      - 1タイルは8×8ピクセルで高精細に描き、拡大してもシャープに表示する(image-rendering: pixelated。検索エリアが広い場合はキャンバス上限のため4×4/2×2へ自動縮小)。
      - メッシュマーカーの表示上限は検索エリアのタイル数×256×256(=全画素)で、全結果行のヒット画素を全て表示する。
      - 1画素は、表示天体毎に複数日の最良辻日時を保持できる(公転により同じ方向を年2回以上通る太陽・月などの日を取りこぼさない)。
    - 天体色のマーカー(辻マーカー)は、コントロール領域で指定した辻時刻(±辻時刻の幅s)に、精度フィルタ以内で辻が成立する画素を再計算して表示する(結果リストの行選択時は、その行の辻時刻で初期化)。
      - 辻マーカーの表示上限も検索エリアのタイル数×256×256(=全画素)で、再計算した集合を全て表示する。
    - 辻マーカー、メッシュマーカーは画素の実寸(DEM標高タイル1画素≒約10m四方)で描くため、ズームに応じて面として見える。
    - 指定した辻時刻で最良精度の画素には、観測点マーカーと同じ大きさの金色のマーカー(ピン:優辻マーカー)を立てて、最良画素の位置を指し示す。

- 74. 「標高オプション」チェックボックス:
  - 機能概要
    - 標高オプションがオンの場合は、検索期間での辻検索をする前に、先に標高グラフの計算アルゴリズムで、可視可能かどうかのOK、NG判断をする。その後、検索期間での辻メッシュ検索を行う。
    - 基本オプションの除外範囲(目的点の半径○m以内の遮蔽を無視)を反映する。除外は「目的点からの距離が除外半径以内のサンプルを無視」で、剣ヶ峯を目的点にした時のお鉢の縁のような、実在する近傍の遮蔽を意図的に無視するための機能(DEMの分解能とは独立)。
    - 可視判定は、許容範囲内の対象画素それぞれを観測点として、統一可視判定(標高グラフの可視判定・辻検索/My辻検索の標高オプションと共通のコア)で行う:
      - グラフ描画(滑らかさ目的の2000点)と可視判定は分離し、可視判定のサンプリングは点数固定ではなく「DEM分解能固定」= ズーム15の半画素(約2m)刻みで経路(画素→目的点の直線)を歩く。経路長に関わらず全てのDEM画素を取りこぼさない。
      - 各サンプルの標高はDEM5A→5B→5C(ズーム15・5mメッシュ)→DEM10B(ズーム14・10mメッシュ)の順で参照する(getElevationと同じフォールバック・同じ丸め)。
      - 可視直線(画素の標高(同チェーン)+観測点高 → 目的点標高)を上回る点が1つでもあればNG(除外範囲=目的点の半径○m以内のNGは無視。端点そのものは判定しない)。
      - 標高グラフ・辻検索・辻メッシュ検索の可視判定は全てこの統一コアを使うため、同じ経路なら同じ判定になる。
    - 先に許容範囲方位角/視高度で対象画素を絞ってから可視判定する。DEM標高タイルは対象領域〜目的点のコリドー(扇形)を先取りし、判定はNGが出た時点で打ち切る。進捗(タイル取得・判定画素数)を表示する。
    - 標高オプションの対象で、辻メッシュ検索を行う。
    - 検索結果の行の標高グラフの列の表示は、その行の辻時刻での、その表示されている精度角距離を出した画素の地点の可視判定を表示する。
    - 標高グラフのアルゴリズムを再利用するので、DEM標高タイルは、一時的にキャッシュして使い回す。
- 検索結果表示領域

        - コントロール領域が閉じている場合。
          - 検索結果表示領域をコントロール領域が下部に閉じている状態で占めて、残りを結果リスト表示領域で占める。
      - 検索結果領域に、宙の窓などが占めない場合。
        - 地図の領域の画面1/3が必要なので、残りの画面2/3を占める。
        - コントロール領域が開いている場合。
          - 検索結果表示領域を結果リスト表示領域とコントロール領域で2分割する。
        - コントロール領域が閉じている場合。
          - 検索結果表示領域をコントロール領域が下部に閉じている状態で占めて、残りを結果リスト表示領域で占める。
    - 検索結果表示領域を最大化しない場合。
      - 検索結果領域に、宙の窓などが画面1/3を占める場合。
        - 地図の領域の画面1/3が必要なので、残りの画面1/3を占める。
        - コントロール領域が開いている場合。
          - 検索結果表示領域を結果リスト表示領域とコントロール領域で2分割する。
        - コントロール領域が閉じている場合。
          - 検索結果表示領域をコントロール領域が下部に閉じている状態で占めて、残りを結果リスト表示領域で占める。
      - 検索結果領域に、宙の窓などが占めない場合。
        - 地図の領域の画面2/3が必要なので、残りの画面1/3を占める。
        - コントロール領域が開いている場合。
