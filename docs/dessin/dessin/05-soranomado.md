# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## 宙の窓メニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- カメラで写真と撮る時に、イメージしやすいように、観測点から目的点方向を画面内でシミュレーションをして、プレビューできるようにする。
### 概要:
- 機能概要
  - 宙の窓
    - 連なる山々や尾根筋の前景に、天の川や太陽や月などの天体が重なる景色をシミュレーションする。
    - 位置情報と日時情報から、天の川や太陽や月の天体の位置を算出し、国土地理院のDEM標高タイルを用いて、山々や尾根筋を描画する。
    - カメラから写真を撮るときに、例えば、センサーサイズは、フルサイズで、35mmのレンズで、絞りはF8で、ピントの合っている範囲は、フォーカスピーキングで赤色で表示する、山々や尾根筋を太陽光ヒルシェード＋標高グレースケールで立体的に表示する、といったカスタマイズができること。
    - 表示する天体は、表示天体メニューの辻ライン表示チェックボックスと連動する。
    - 月以外の天体は、視半径を考慮して、面積を持つ円で描画をし、月は、満ち欠けがるので、それをシミュレーションをする面積を持つ領域で表現するが、新月や新月に近いときは、どこに月があるかわからないので、月も、それ以外の天体も、中心座標を十字記号(+)で印をつける。また、月は、視半径の円を細い線で描画し、どれくらい満ち欠けがあるかわかるようにする。
    - プレビュー画面は、標高グラフや天の川儀のように画面3分の1に表示する。
- デザイン概要
  - 凡例:0️⃣:段抜き、1️⃣:1行目、2️⃣:2行目、1️⃣:2️⃣:1行目の中の2行目、以下同様
  - 0段目:
    - 1. 「宙の窓」ラベル:
      - 太字、左寄せ
    - 2. 「▼」ラベル:
      - 右寄せ
    - 共通事項:
      - タップすると、宙の窓メニューが開閉する。
      - 背景グレー、不透明
      - 初期状態:閉じている。
  - 1段目:
    - 3. 「センサーサイズ:」リストボックス:
      - カメラメーカー各社とスマートフォンのセンサーサイズの代表的なサイズを15個くらいまで選択できるようにする。
      - 初期値:フルサイズ
  - 2段目:
    - 4. 「アスペクト比:」ラベル:
      - ファインダーのアスペクト比を指定できる。
    - 5. 「横」テキストボックス:
      - ファインダーのアスペクト比の横を指定するテキストボックス。
      - 初期値:3
      - 制約:1〜100
      - プレースホルダー:「1〜100」
    - 6. 「縦」テキストボックス:
      - ファインダーのアスペクト比の縦を指定するテキストボックス。
      - 初期値:2
      - 制約:1〜100
      - プレースホルダー:「1〜100」
  - 3段目:
    - 7. 「焦点距離:」ラベル:
      - ラベルの右側に8.リストボックス、9.スライダーで選択されている焦点距離を表示する。
      - カメラのレンズの焦点距離を表示する。
      - 8.焦点距離リストボックス、9.焦点距離スライダーと連動する。
      - 例:35mm
  - 4段目:
    - 8. 焦点距離リストボックス:
      - カメラのレンズの焦点距離を指定する。
      - 7.焦点距離ラベル、9.焦点距離スライダーと連動する。
      - リストボックスの値リスト
        - 各カメラメーカーとスマートフォンの焦点距離を10mmから3000mmまで、40個くらいまで選択できるようにする。
        - 10,11,12,13,14,15,16,17,18,20,24,26,28,30,35,40,50,58,70,75,85,105,120,135,140,180,200,250,400,500,600,800,1000
      - 初期値:35
  - 5段目:
    - 9. 焦点距離スライダー:
      - カメラのレンズの焦点距離を指定する。
      - 7.焦点距離ラベル、8.焦点距離リストボックスと連動する。
      - 制約:6〜3000、ステップ1
  - 6段目:
    - 10. 「画角:」ラベル:ラベルのみ
  - 7段目:
    - 11. 「水平:」ラベル:
      - 指定した焦点距離の水平画角を表示する。
      - 例:94°
    - 12. 「垂直:」ラベル:
      - 指定した焦点距離の垂直画角を表示する。
      - 例:45°
    - 13. 「対角:」ラベル:
      - 指定した焦点距離の対角画角を表示する。
      - 例:50°
  - 8段目:
    - 14. 「F値:」ラベル:
      - ラベルの右側に、15.F値スライダーで指定した値を表示する。
    - 15. F値スライダー:
      - カメラのレンズのF値(絞り)を指定する。
      - 初期値:2.8
      - 制約:0.95,1〜22までの1/3ステップ
  - 9段目:
    - 16. 「ピント距離:」ラベル:
      - 17.ピント距離スライダーで指定した値を表示する。
      - 例:1000m
  - 10段目:
    - 17. ピント距離スライダー:
      - カメラのファインダーでフォーカスピーキングを表示するためのピント距離を表示する。
      - 初期値:1000
      - 制約:0〜10000、ステップ1
  - 11段目:
    - 18. 「:フィッシュアイ」チェックボックス:
      - チェックオンにすると、魚眼レンズで表示したようにシミュレーションできる。
      - 初期値:オフ
  - 12段目:
    - 19. 「:フォーカスピーキング」チェックボックス:
      - チェックオンにすると、フォーカスピーキングを赤色でシミュレーションできる。
      - 初期値:オン
  - 13段目:
    - 20. 「:グレースケール」チェックボックス:
      - 山々の前景の色付けを切り替える。どちらも太陽光ヒルシェード(陰影)で立体的に表示する。
      - チェックオン:視界範囲内の最高標高を白色とした標高グレースケールに、太陽光ヒルシェードを重ねる(標高と尾根の向きが分かる)。
      - チェックオフ:一様グレーに太陽光ヒルシェードのみを重ねる(純粋なレリーフ表示)。
      - 初期値:オン
  - 14段目:
    - 21. 「過焦点距離:」ラベル:
      - 指定したセンサーサイズ、焦点距離、F値の場合での、過焦点距離を表示する。
      - 例:13.5m
  - 15段目:
    - 22. 「合焦範囲:」ラベル:
      - 指定したセンサーサイズ、焦点距離、F値の場合での、合焦範囲を表示する。
      - 例:2.5m 〜 3.8m
  - 16段目:
    - 23. 「被写界深度:」ラベル:
      - 指定したセンサーサイズ、焦点距離、F値の場合での、被写界深度を表示する。
      - 例:1.4m
  - 17段目:
    - 24. 「基準方位角:」テキストボックス:
      - 基準方位角を観測点緯度経度と目的点緯度経度から算出
      - 辻検索の基準方位角とは連動しない。
      - 初期値:算出値
      - 制約:0〜360、ステップ0.01
      - プレースホルダー:「北から時計回り(°)」
  - 18段目:
    - 25. 「基準視高度:」テキストボックス:
      - 基準視高度を観測点標高と目的点標高から算出
      - 辻検索の基準視高度とは連動しない。
      - 初期値:算出値
      - 制約:−360〜360、ステップ0.01
      - プレースホルダー:「水平から上向き(°)」
  - 19段目:
    - 26. 「オフセット方位角:」テキストボックス:
      - 観測点のカメラの向きの変更を、基準方位角からのズレ量のオフセット方位角で入力する。
      - 辻検索のオフセット方位角とは連動しない。
      - 初期値:0
      - 制約:-360〜360、ステップ0.5
      - プレースホルダー:「基準から時計回り(°)」
  - 20段目:
    - 27. 「オフセット視高度:」テキストボックス:
      - 観測点のカメラの向きの変更を、基準視高度からのズレ量のオフセット視高度で入力する。
      - 辻検索のオフセット視高度とは連動しない。
      - 初期値:0
      - 制約:−360〜360、ステップ0.5
      - プレースホルダー:「基準から上向き(°)」
  - 21段目:
    - 28. 「視界範囲:」テキストボックス:
      - プレビュー画面内にどの範囲の奥行きの視界範囲を含めるかを指定するテキストボックス。
      - 29.視界範囲スライダーと連動する。
      - 初期値:観測点と目的点間の距離(km)を切り上げた値(0km〜この距離)
      - 制約:1〜300
      - プレースホルダー:「1〜300(km)」
  - 22段目:
    - 29. 視界範囲スライダー:
      - プレビュー画面内にどの範囲の奥行きの視界範囲を含めるかを指定するスライダー。
      - 28.視界範囲テキストボックスと連動する。
      - 初期値:観測点と目的点間の距離(km)
      - 制約:1〜300、ステップ1
  - 23段目:
    - 30. 「:天体軌跡」チェックボックス:
      - 表示天体の中心点の軌跡を、日時情報で指定される日付(前後1日を含む)の範囲で、天体色で細線で、プレビュー画面内に描画するか、しないかを選択できる。
      - 各日(前日・当日・翌日)の0:00〜23:59を1本ずつ、計3本の線で描画する。
      - 初期値:オン
    - 31. 「:画面中心(+)」チェックボックス:
      - プレビュー画面の中心座標を十字記号(+)で印をつけたマークを表示/非表示を切り替えられる。
      - 初期値:オン
### 仕様詳細:
- プレビュー画面:
  - 機能概要
    - 位置情報と日時情報から、天の川や太陽や月の天体の位置を算出し、国土地理院のDEM標高タイルを用いて、山々や尾根筋を描画する。
    - ダウンロードしたDEM標高タイルは、一時的にキャッシュして使い回す。
    - 視界範囲は、観測点からの距離0kmから、観測点と目的点(相手)の距離(km)を切り上げた数値の距離までを初期値とし、その奥行きを、レンズの焦点距離で指定する画角の範囲の扇形で、DEM標高タイルをダウンロードする。
    - 手前の山の輪郭や、手前に伸びる尾根筋が立体的に3Dで分かるように陰影をつけて描画する。陰影は、太陽の位置を光源とした陰影(太陽光ヒルシェード)と、視界範囲内の最高標高を白色とした標高グレースケールを組み合わせる(尾根の向きで明暗がつき、立体感が出る)。日時が夜間で太陽が地平線下のときも、太陽の方位を保ったまま光源の高度を底上げして、尾根のレリーフ(立体)を維持する。
    - DEM標高タイルの取得とPNGデコード・標高化は、ワーカープールで並列並行非同期処理する。取得に時間がかかる場合は、プレビュー上端に進捗バーを表示する(ワーカー/OffscreenCanvas非対応環境ではメインスレッドで逐次取得にフォールバックする)。
    - カメラから写真を撮るときに、例えば、センサーサイズは、フルサイズで、35mmのレンズで、絞りはF8で、ピントの合っている範囲は、フォーカスピーキングで赤色で表示する、山々や尾根筋を太陽光ヒルシェード＋標高グレースケールで立体的に表示する、といったカスタマイズができること。
    - 表示する天体は、表示天体メニューの辻ライン表示チェックボックスと連動する。
    - 月以外の天体は、視半径を考慮して、面積を持つ円で描画をし、月は、満ち欠けがるので、それをシミュレーションをする面積を持つ領域で表現するが、新月や新月に近いときは、どこに月があるかわからないので、月も、それ以外の天体も、中心座標を十字記号(+)で印をつける。また、月は、視半径の円を細い線で描画し、どれくらい満ち欠けがあるかわかるようにする。
    - 天の川は、どの位置に天の川があるか分かるように、天の川写真が背景になるように表示する。
    - 天の川や太陽や月などの表示天体の中心点の軌跡を、日時情報で指定される日付(前後1日を含む)の範囲で、天体色で細線で、プレビュー画面内に描画する。各日(前日・当日・翌日)の0:00〜23:59を1本ずつ、計3本の線で描く。
    - プレビュー画面は、標高グラフや天の川儀のように画面3分の1に表示する。
    - 標高グラフと天の川儀とは、トグルボタンで排他的に表示するが、辻検索の結果とは、同時に表示できるようにする。
    - 辻検索の結果の行を選択した場合は、日時情報が切り替わるので、それに合わせて、プレビューも描画される。
    - プレビュー画面の中心座標を十字記号(+)で印をつける。
- 共通機能/デザイン
  - テキストボックス:
    - 未入力でフォーカスが外れた場合、元の値を復元する。
    - title属性でテキストボックスの内容をツールチップで表示する。
    - input:type=textは、最大文字数150文字とする。
    - XXS対策で、入力内容をタグエスケープする。
    - フォーム、appState、ローカルストレージで、整合性が取れるようにする。
  - 背景色:
    - 1〜9段目は、背景白で、少し透明で、背景の地図が見える。
