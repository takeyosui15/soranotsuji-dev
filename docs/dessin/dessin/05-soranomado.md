# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## 宙の窓メニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- カメラで写真と撮る時に、イメージしやすいように、観測点から目的点方向を画面内でシミュレーションをして、プレビューできるようにする。
### 概要:
- 機能概要
  - 宙の窓
    - 連なる山々や尾根筋の前景に、天の川や太陽や月などの天体が重なる景色をシミュレーションする。
    - 位置情報と日時情報から、天の川や太陽や月の天体の位置を算出し、国土地理院のDEM標高タイルを用いて、山々や尾根筋を描画する。
    - カメラから写真を撮るときに、例えば、センサーサイズは、フルサイズで、35mmのレンズで、絞りはF8で、ピントの合っている範囲は、フォーカスピーキングで赤色で表示する、山々や尾根筋を太陽光ヒルシェード＋標高グレースケールで立体的に表示する、といったカスタマイズができること。
    - 表示する天体は、表示天体メニューの辻ライン表示チェックボックスと連動する。
    - 月以外の天体は、視半径を考慮して、面積を持つ円で描画をし、月は、満ち欠けがるので、それをシミュレーションをする面積を持つ領域で表現するが、新月や新月に近いときは、どこに月があるかわからないので、月も、それ以外の天体も、中心座標を十字記号(+)で印をつける。また、月は、視半径の円を細い線で描画し、どれくらい満ち欠けがあるかわかるようにする。
    - プレビュー画面は、標高グラフや全天儀のように画面3分の1に表示する。

### 仕様詳細:
- プレビュー画面:
  - 機能概要
    - 位置情報と日時情報から、天の川や太陽や月の天体の位置を算出し、国土地理院のDEM標高タイルを用いて、山々や尾根筋を描画する。
    - ダウンロードしたDEM標高タイルは、一時的にキャッシュして使い回す。
    - 視界範囲は、観測点からの距離0kmから、観測点と目的点(相手)の距離(km)を切り上げた数値の距離までを初期値とし、その奥行きを、レンズの焦点距離で指定する画角の範囲の扇形で、DEM標高タイルをダウンロードする。
    - 手前の山の輪郭や、手前に伸びる尾根筋が立体的に3Dで分かるように陰影をつけて描画する。陰影は、太陽の位置を光源とした陰影(太陽光ヒルシェード)と、視界範囲内の最高標高を白色とした標高グレースケールを組み合わせる(尾根の向きで明暗がつき、立体感が出る)。日時が夜間で太陽が地平線下のときも、太陽の方位を保ったまま光源の高度を底上げして、尾根のレリーフ(立体)を維持する。
    - DEM標高タイルの取得とPNGデコード・標高化は、ワーカープールで並列並行非同期処理する。取得に時間がかかる場合は、プレビュー上端に進捗バーを表示する(ワーカー/OffscreenCanvas非対応環境ではメインスレッドで逐次取得にフォールバックする)。
    - カメラから写真を撮るときに、例えば、センサーサイズは、フルサイズで、35mmのレンズで、絞りはF8で、ピントの合っている範囲は、フォーカスピーキングで赤色で表示する、山々や尾根筋を太陽光ヒルシェード＋標高グレースケールで立体的に表示する、といったカスタマイズができること。
    - 表示する天体は、表示天体メニューの辻ライン表示チェックボックスと連動する。
    - 月以外の天体は、視半径を考慮して、面積を持つ円で描画をし、月は、満ち欠けがるので、それをシミュレーションをする面積を持つ領域で表現するが、新月や新月に近いときは、どこに月があるかわからないので、月も、それ以外の天体も、中心座標を十字記号(+)で印をつける。また、月は、視半径の円を細い線で描画し、どれくらい満ち欠けがあるかわかるようにする。
    - 天の川は、どの位置に天の川があるか分かるように、天の川写真が背景になるように表示する。さらに、天の川の環(銀河赤道の大円)を白色の線で表示する。天の川の中心座標(銀河中心)は、他天体と同じ天体色の十字記号で表示し、その中心座標の軌跡(前後1日を含む計3本)も天体色の線で表示する。
    - 天の川や太陽や月などの表示天体の中心点の軌跡を、日時情報で指定される日付(前後1日を含む)の範囲で、天体色で細線で、プレビュー画面内に描画する。各日(前日・当日・翌日)の0:00〜23:59を1本ずつ、計3本の線で描く。
    - プレビュー画面は、標高グラフや全天儀のように画面3分の1に表示する。
    - 標高グラフと全天儀とは、トグルボタンで排他的に表示するが、辻検索の結果とは、同時に表示できるようにする。
    - 辻検索の結果の行を選択した場合は、日時情報が切り替わるので、それに合わせて、プレビューも描画される。
    - プレビュー画面の中心座標を十字記号(+)で印をつける。
    - 目的点(基準方位角・基準視高度=観測点から目的点を見た方向)に、赤い十字記号(+)の目的点マーカーを表示する。地形に隠れず常に見え、画面サイズに依らず一定の大きさで表示する。オフセットが0のときは画面中心の十字と重なる。
    - プレビュー画面は、マウスのドラッグ(スマホは2本指のスクロール)でパン(視線移動)できる。画面の内容が指に追従して動き、オフセット方位角・オフセット視高度がそれに連動して更新される(メニューの数値表示とも同期)。
