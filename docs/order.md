> #### 4. P12(地理院サイトのTLS)とP13(タイル単位の合成)の説明
>
> - P12: 地理院のサーバーは、暗号化通信の「安全な再交渉」という古い取り決めに未対応で、新しいOpenSSL(3系)を使うcurlは既定で接続を断ります。たけちゃんのMacのブラウザやcurlでは問題ありません(この作業環境の話です)。手当ては「証明書の検証はそのままに、古い再交渉だけを許す設定」を渡すことで、年1回の取り直し用に `tools/kashimap/fetch-gsi-1003zan.sh` にしました。普段は使いません。
> - P13: 地図ライブラリは「このURLのタイル画像をちょうだい」と自動で取りに行きます。addProtocolは「そのURLの取り方は私(アプリ)が決める」と登録する仕組みで、地理院の標高タイルを色の画像に変換する所で既に使っています。可視マップでは、地図が「この範囲のタイルをちょうだい」と言うたびに、アプリが選んだ山の島をそのタイルの範囲に描いて数え、金色の濃さや縞を描いた画像を作って渡す、という案でした。P4(画面全体を一枚で描き直す)との違いは「動いた分のタイルだけ描き足せる」ことです。ただしQ5の変更で「画面内の最大の数」を先に知る必要が出たので、第1版はP4(画面全体を数えてから描く)が素直です。P13は代案として実装デッサンで比べます。
