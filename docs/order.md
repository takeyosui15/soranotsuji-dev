**4. PCのダブルクリック化 → 対応済み(ご心配の点も問題ありません)**
- **PC(マウス操作)では、地図クリックによる観測点/目的点の移動と、メッシュマーカー・辻マーカーの選択を「ダブルクリック」に変更**しました。ドラッグ途中でマウスボタンを離してしまってもシングルクリック扱いなので、観測点が動いてしまう誤操作は起きなくなります。

- あわせて、誤動作防止のため**PCでは地図のダブルクリックズームを無効化**しました(ズームは「+/-」ボタン・ホイール・ピンチで従来どおり)。

**5. 地図のスクロール → ボタン方式(◀▶/▲▼)で実装しました**
