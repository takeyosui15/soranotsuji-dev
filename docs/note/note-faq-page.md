# Q. スマホで登録した内容とパソコンで登録した内容が異なるようです。
A.
はい、そうです。端末ごと(ブラウザごと)に別々に保存されます。同じ内容にしたい時は、Google アカウントでログインして、Google ドライブ経由で揃えられます。
A詳細.
登録内容は、各端末のブラウザの中(ローカルストレージ)に保存されます。スマホとパソコンはもちろん、同じスマホでも Chrome・Safari・LINE の中のブラウザでは別々に保存されます。本サービスはアカウント登録をしない代わりに、登録内容をサーバー側に保存しない仕組みです。
端末間で同じ内容にしたい時は、次の2つの方法があります。
- 方法①
  - Google アカウントでログイン(画面上部の 🈚️ アイコン、またはバックアップ/インポートメニューの「ログイン」ボタン)します。
  - ログイン後は、そのアイコンが同期の状態を示します(😢=ドライブにファイルが無い → 押すと作成 / 👍=同期済み / 👎=端末とドライブに差がある → 押すと「①端末の内容をGoogleドライブに保存」「②Googleドライブの内容を端末に読み込み」を選ぶ画面)。
  - もう一方の端末でもログインして「②Googleドライブの内容を端末に読み込み」を選びます。
  - 宙の辻が求める権限は「宙の辻で作った/選んだファイルだけ」で、ログイン情報は端末に保存しません。
- 方法②
  - バックアップ/インポートメニューの「バックアップ」でファイル(JSON)に書き出し。
  - もう一方の端末で「インポート」で読み込みます。
My観測点・My目的点・My辻検索・My天体は、Myセットとして Google スプレッドシートとも連携できます。

# Q. Hom / 推山 ボタンがリセットできません。
A.
リセットは「観測点(°)の欄(Hom の場合)/目的点(°)の欄(推山の場合)を**空にしてから**ボタンを押す」操作です。欄に文字(座標や地名)が入ったまま押すと、リセットではなく「登録」または「呼び出し」になります。
A詳細.
位置情報メニューの Hom(観測点)/推山(目的点)ボタンは、1つのボタンで3つの働きをします。どれになるかは「押す時に、その横の (°) の欄が空かどうか」と「登録済みかどうか」で決まります。
- 欄が空 → **リセット**
  - 登録を消して、その点を初期値(観測点=東京タワー(高さ150m)/目的点=富士山)に戻します。名前・座標・標高・高さの全部が初期値になり、地図もそこへ移動して、「初期値をリセットし、デフォルトに戻しました」と出ます。
- 欄に文字が入っていて、まだ登録が無い → **登録**
  - いま設定している観測点/目的点を、Home/推し山として登録します。登録するとボタンの色が変わり、ボタンの説明が「登録済みの観測点(目的点)を呼び出し」になります。
- 欄に文字が入っていて、登録済み → **呼び出し**
  - 登録してある場所へ、観測点/目的点を移動します(いまの場所は登録に上書きされません)。
- リセットの手順
  - 観測点(°)または目的点(°)の欄(「Plus Code、緯度,経度」と薄く書いてある欄)の中身を全部消す(スマホは欄を長押し → 全選択 → 削除。PC は欄をクリックして Ctrl+A(Mac は ⌘A)→ Delete)。
  - 欄が空のまま、Hom または 推山 を押す。
- 登録し直したい時(別の場所を Home/推し山にしたい時)
  - 登録済みのまま押すと「呼び出し」になるので、先に上の手順でリセットして登録を消し、その後、新しい場所を設定してから(欄に文字が入っている状態で)もう一度押して登録します。
- 補足
  - Hom と 推山 は別々に登録・リセットします。
  - 登録した場所は端末の中(ローカルストレージ)に保存されます。Google ドライブ同期やバックアップにも含まれます。

# Q. 不具合かなと思ったら。 / アプリデータを削除したい。
A.
まず、ブラウザの再読み込み(更新)を試してください。直らなければ、**リセット URL**(https://soranotsuji.net/reset.html)から登録内容を削除して、初期状態に戻してください。削除の前に、必要ならバックアップ(Google ドライブまたはファイル)を取ってください。
A詳細.
登録内容は端末のブラウザの中に保存されるため、スマホとパソコン、同じスマホでも Chrome・Safari・LINE の中のブラウザでは、別々に保存されます。一度でも開いたブラウザには、その時のデータが残ります。
各端末・各ブラウザからリセット URL を開いて、それぞれ削除することで、宙の辻のアプリデータを完全に削除できます。
「すべてのデータを消去する」は、登録内容(ローカルストレージ)のほか、端末に貯めた地図(地理タイル)・標高タイルの控え(オフライン表示用)と天気のキャッシュも消去します。Google ドライブに保存したファイルは消えません。リセット URL のページにも「全データをJSONでバックアップ(ダウンロード)」「バックアップJSONから復元」のボタンがあります。
- 完全削除手順
  - リセット URL(https://soranotsuji.net/reset.html)にアクセスする。もしくは、宙の辻のヘルプの下部からリセット URL にアクセスする。
  - 画面下部の赤いボタン「すべてのデータを消去する」をクリック・タップする。
  - 「OK」ボタンを押す。
  - そのままブラウザ(Chrome、Safari、LINE など)の画面を閉じる。
  - 今までアクセスした端末・ブラウザの数だけ、1.〜4.を繰り返す。

# Q. 「辻ライン」と「辻検索」は、表示結果が異なるようです。どちらが正しい、もしくは、正確でしょうか。
A.
辻検索の方が正確です。辻ラインは「場所の目安」、辻検索は「その場所での正確な日時」です。
A詳細.
辻ラインは、目的点(山)から「この時刻に重なって見える場所」を逆算して、地図に線で描くものです。
線の上のどの地点も「いま設定している観測点の標高(と観測点高)」で計算しているため、実際の地面の高さが違う場所では線の位置がずれます。また、辻ラインの ◎/○/△ の帯は方位角のずれだけで決めていますが、辻検索の精度記号は方位角と視高度のずれを合わせた角距離で決めています(線は目的点から 400km 以内まで描きます)。
辻検索は、観測点の緯度経度・標高が決まっているので、天体位置計算エンジン(Astronomy Engine)の高精度な計算結果をそのまま使えます。
辻ラインで場所の当たりを付け、その場所を観測点にして辻検索で日時を確かめる、という使い方をおすすめします。

# Q. 地名検索で無反応になってしまう。
A.
しばらく時間を置いてから、ページを再読み込みして再検索してください。
A詳細.
地名検索は国土地理院の検索サービスを使っています(国土地理院で見つからなかった時は OpenStreetMap の検索サービスで探し直します。端末のタイムゾーンが日本以外の時は、最初から OpenStreetMap だけで探します)。
短い時間に何度も検索すると、サービス側の呼び出し制限で「該当する地名が見つかりませんでした」になったり、応答に時間がかかったりすることがあります。
また、観測点(°)/目的点(°)の欄は「入力内容が変わった時」に検索するため、同じ文字のまま Enter を押し直しても検索は走りません(観測点名/目的点名の欄は Enter のたびに検索します)。
その場合は、ページを再読み込み(再読み込みしても登録内容は消えません)、またはブラウザを一度閉じてから、しばらく時間を置いて再検索してください。

# Q. 「場所が見つかりませんでした」となってしまう。
A.
地図を拡大してダブルタップ(PC はダブルクリック)で場所を決めるか、観測点(°)/目的点(°)の欄に緯度・経度を直接入力してください。
A詳細.
地名検索で、その地名の場所が見つからなかった場合です(画面の表示は「該当する地名が見つかりませんでした」)。次のどれかで場所を決められます。
- 地図を拡大して、目的の場所をダブルタップ/ダブルクリックする(1回のタップ/クリックでは動きません。ラジオボタンで、観測点/目的点のどちらを動かすかを選べます)。
- Google マップなどで緯度・経度を調べて、位置情報メニューの観測点(°)/目的点(°)の欄に「緯度,経度」(例: 35.3606,138.7274)の形で貼り付ける。調べ方は Google のヘルプ「Googleマップで場所の座標を取得する」を参照してください。
- Google マップの「プラスコード」を貼り付ける。フルコード(例: 8Q7W9P6G+6X)のほか、短縮形(例: 9P6G+6X 富士宮市)も使えます。短縮形は基準になる地名の候補を選ぶとその近くに展開され、地名を省くと地図の中心が基準になります。

[ご参考]
・Google マップで緯度と経度で検索する
https://support.google.com/maps/answer/18539
・plus code を使用して場所を検索、共有する
https://support.google.com/maps/answer/7047426

# Q. 地名検索した場所の標高が少しずれている。 / 実際の山頂の高さと違う。
A.
検索でヒットする「地点」と、実際の「最高地点」がわずかに異なるためです。地図をダブルタップ/ダブルクリックしてピンを置き直すか、「高移」ボタンで近くのより高い小ピークへ動かしてください。
A詳細.
検索機能でヒットする場所は、その地名の「代表地点(文字が表示される場所など)」であり、必ずしも地理的な「最高地点(山頂の標識がある場所など)」とは一致しません。
【解決策】
①検索で大まかな場所に移動した後、地図(国土地理院の地形図)を拡大して、目的の場所(山頂など)をダブルタップ/ダブルクリックして、ピンを置き直してください(ピンのドラッグはできません)。標高は地点を動かすたびに自動で取り直します。
②位置情報メニューの「高移」ボタン(準最高地点移動)を押すと、ラジオボタンで選択中の観測点/目的点を、国土地理院の標高データで調べた「いまより高い小ピーク(局所的な高まり)」のうち最も近いものへ自動で動かします(探す範囲は現在地点を中心におよそ ±0.5〜1km)。見つからない時は「近傍により高い地点が見つかりませんでした」と出ます。必ずしも最高地点に着くとは限らないので、動かした後に地図で位置を確かめてください。

# Q. 地図上に観測点/目的点のマーカー📍が表示されない。
A.
ページを再読み込みしてください。それでも出ない時は、地図を少し動かす(ドラッグ・拡大縮小)か、ブラウザを一度閉じて開き直してください。
A詳細.

# Q. 月齢が0もしくは30にならない。
A.
朔望月を 29.53058886 日と定義していることと、日時の内部表現(ミリ秒)と表示の丸め(小数1桁)の都合で、月齢は「0.0」または「29.5」と表示され、ちょうど「0」や「30」にはなりません(30 を入力すると、30−29.53=0.5 の日時に移動します)。
A詳細.
日時情報メニューの「月齢」欄に「0」を入力した場合、
①月齢が「0」(新月)になる日時を探します。
②その日時(ミリ秒単位)をカレンダーに設定します。
③設定した日時から、表示のために月齢を計算し直します。← この再計算で、ミリ秒より細かい分のずれが出ます。
天体位置計算エンジン(Astronomy Engine)は内部でミリ秒より高い精度で計算しているため、再計算した月齢は 0 のごくわずかに手前(29.53…)か先(0.00…)になり、小数1桁に丸めた表示は「29.5」または「0.0」になります。

# Q. 辻メッシュ検索のメッシュマーカー1つ(1タイル)は何m四方ですか。
A.
マーカー1つは、国土地理院の標高データの1画素で、**およそ8〜10m四方**です(緯度で少し変わります。北海道では小さく、沖縄では大きくなります)。
A詳細.
- 辻メッシュ検索は、観測点のまわりの標高データ(国土地理院 標高タイル・ズーム14)の全ての画素を観測点として辻検索し、精度フィルタに入った画素にマーカーを置きます。1画素の大きさは、緯度35°付近で約8m四方です。
- 「検索エリア」の 3×3・4×4・5×5・6×6 は、この標高データの「タイル」(256×256画素=緯度35°付近で約2km四方)の枚数です。3×3 で約6km四方、6×6 で約12km四方の範囲を調べます。
- マーカーは画素の実寸で描くので、地図を拡大すると面(格子)として見え、縮小すると点のように見えます。マーカーの上にマウスを載せる(スマホはタップ)と、その画素のヒット件数と詳細リストが出ます。

# Q. 宙の窓検索でブラウザが落ちます。
A.
多くはスマホのメモリ不足です。宙の窓メニューの「都市モード」をオフにするか「表示タイル数」を小さく(初期値30 → 10前後)し、「写真テクスチャ」をオフ、「画像サイズ(手動:MB/枚)」を小さくしてお試しください。他のタブやアプリを閉じるのも効きます。
A詳細.
宙の窓は、地形・写真テクスチャ・建物(都市モード)・天体を3Dで描くため、スマホではメモリを多く使います。ブラウザはメモリが足りなくなると、警告なしにページを閉じる(落ちる)ことがあります。効く順に:
- 宙の窓メニューの「**都市モード**」をオフにする。都市部の建物データは最も重い物です。オンのままにするなら「**表示タイル数**」を 30 より小さく(10前後)。
- 「**写真テクスチャ**」(山肌に航空写真)をオフにする。
- 「**画像サイズ(手動:MB/枚)**」を小さくする(静止画・動画の書き出しの大きさ)。
- パノラマ・魚眼・広い画角より、標準の画角の方が軽くなります。
- 他のタブやアプリを閉じる。ブラウザを一度終了して開き直す。
- それでも落ちる場合は、同じ条件を PC で開くか、スマホでは条件を軽くしてプレビューし、PC で書き出す、という使い分けをおすすめします。
落ちた後に設定が戻っていることがあります。設定は端末に保存されているので、必要ならバックアップ(Google ドライブまたはファイル)から戻せます。

# Q. 更新したら、辻検索や可視判定の結果が前と変わった。
A.
v1.98.0 で、気差(大気差)の設定の初期値が「オン」になり、保存済みの設定も一度だけオンに切り替わったためです。以前どおりにしたい時は、設定メニューで「気差係数 K」の先頭のチェックと「:気差オプション」の両方をオフにしてください。
A詳細.
遠くの景色は空気の層で光が曲がって(気差)、実際より少し浮き上がって見えます。v1.98.0 から、地形の見通し(気差係数 K)と天体の見かけ高度(大気差)の2つを分けて扱い、どちらも既定でオンにしました。
このため、辻検索の時刻・可視判定(OK/NG)・辻ラインの位置が以前と少し変わることがあります(以前からオンで使っていた方も、気温減率の初期値が変わったため、気象条件が初期値のままなら K が約0.169から0.132に変わります)。
詳しくはリリースノート v1.98.0 の「4. 気差 (大気差) の扱いを見直し: 2つのスイッチに」をご覧ください。

# Q. 電波の無い所(山の上など)でも使えますか。
A.
使えます(v1.99 から)。電波のある所で一度宙の辻を開いておけば、電波が無くても宙の辻を開き直せます。地図・標高は「一度見た範囲」だけ使えます。
A詳細.
- 準備: ①電波のある所で宙の辻を一度開いて少し待ちます(バックアップ/インポートメニューの「本体の控え」に件数・版・最終更新日時が出れば完了)。②使う予定の範囲の地図を表示し、標高グラフや辻検索を一度動かしておきます(地図・標高の控えができます)。
- 使う: 電波が無い所で宙の辻を開くと、版の横に「(オフライン表示)」が出ます。辻ライン・辻検索・辻メッシュ検索・標高グラフ・宙の窓は、控えのある範囲で動きます。
- できないこと: 地図・標高・建物(PLATEAU)・天気は一度見た範囲だけです。Google ドライブ同期・地名検索・天気の取得には通信が要ります(Plus Code のフルコードは通信なしで変換できます)。
- iPhone/iPad: Safari も Chrome も同じ仕組み(WebKit)で、7日ほど宙の辻を開かないとブラウザが控えを消すことがあります。「ホーム画面に追加」(共有ボタン→ホーム画面に追加)した宙の辻は消されません。ホーム画面の宙の辻とブラウザのタブの宙の辻はデータの入れ物が別なので、My観測点などはバックアップ/インポートか Google ドライブ同期で移してください。
- Android: Chrome のメニューから「ホーム画面に追加」すると、容量不足でも消されにくくなります(バックアップ/インポートメニューの「永続化を要求」も)。
- 控えの大きさ: 地理タイル・標高タイル・建物はそれぞれ 1GB まで(端末ごとに上限(MB)を変えられます。空欄にすると既定に戻ります)。30日使っていない物と上限を超えた分は自動で片付きます。天気の控えは取ってから2時間で取り直します(古い物は自動で消えます)。「本体の控えを削除」「地理タイルを全削除」などでいつでも空にできます(削除すると、次に開く時に通信して作り直します)。

# Q. Google でログインすると何ができますか。安全ですか。
A.
登録内容と設定の端末間同期(Google ドライブ)と、Myセットのスプレッドシート連携ができます。宙の辻が求める権限は「宙の辻で作った/選んだファイルだけ」で、ログイン情報(アクセストークン)は端末にも保存せず、ログアウトで Google 側の許可も取り消します。
A詳細.
ログインは任意です。ログインしなくても、宙の辻の全ての計算機能は使えます。
ログインで使える機能は、①端末の内容を Google ドライブに保存/読み込み(PC⇄スマホの同期。Home/推し山・表示天体・My天体・My観測点・My目的点・My辻検索・Myセット・設定の全データ)、②Myセットの Google スプレッドシートへの保存/読み込み、③Myセットの「追加」ボタンで、ドライブにある既存の Google スプレッドシートを Google のファイル選択画面(ピッカー)から選んで紐付ける、の3つです。
Google のアカウント画面(https://myaccount.google.com/permissions)で、いつでも許可を取り消せます。詳しくはプライバシーポリシー(https://soranotsuji.net/privacy.html)をご覧ください。

# Q. 「標高フィルタ」が見当たりません。
A.
v1.98.0 で「可視フィルタ」に名前が変わりました(辻検索・辻メッシュ検索・My辻検索)。働きは同じで、目的点が見通せる場所・日時だけに絞り込みます。My辻リストの CSV の列名も v1.99.1 から「可視フィルタ」「可視OKフィルタ」「可視NGフィルタ」になりました(古い列名で書き出したファイルも、そのまま読み込めます)。
