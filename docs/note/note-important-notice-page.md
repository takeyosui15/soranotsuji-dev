# 【重要な】お知らせ（宙の辻 - Sora no Tsuji）

# ■2026/10/23 CSV の列名が変わります(v1.99.4)

○My辻リストの CSV(55〜57列目)

My辻リストを CSV で書き出した時の列名のうち、次の3つが変わります。

- 「標高フィルタ」→「可視フィルタ」
- 「標高OKフィルタ」→「可視OKフィルタ」
- 「標高NGフィルタ」→「可視NGフィルタ」

v1.98.0 で画面の名前を「可視フィルタ」に変えた時、CSV の列名だけは互換のために残していましたが、分かりにくいので列名も合わせました。

**古い列名で書き出したファイルは、そのまま読み込めます**(読み込みは列の名前ではなく列の位置で行うため)。表計算ソフトなどで列名を見て処理している場合だけ、新しい列名に合わせてください。

○File取得の CSV と結果リストの「標高グラフ」列(CSV では65列目)

辻検索・辻メッシュ検索・My辻検索の「File取得」で保存する CSV の列「標高グラフ」(可視判定の結果 OK/NG/-)が「可視判定」になります。画面の結果リストの列名も同じです。
File取得の CSV は宙の辻に読み込むものではないので、古いファイルに影響はありません。表計算ソフトなどで列名を見て処理している場合だけ、新しい列名に合わせてください。
