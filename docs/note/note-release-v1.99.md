## v1.99.1 — 電波の無い所でも開けるようになりました(2026-10-XX)

### オフラインで開ける
- 一度開いておけば、電波の無い所でも宙の辻を開き直せます。開く時はいつも最新を取りに行き、取れない時だけ端末の控えを使います(版の横に「(オフライン表示)」が出ます)。
- 新しい版は、全部そろって確かめてから入れ替わります。途中で電波が切れても、古い版のまま動きます。
- 使い方は「よくあるお問い合わせ」の「電波の無い所でも使えますか」をご覧ください(iPhone/iPad は「ホーム画面に追加」がおすすめです)。

### 端末のデータの管理
- バックアップ/インポートメニューに「端末のデータ」の欄ができました。本体の控え・地理タイル・標高タイル・建物(PLATEAU)・天気の控え・設定の件数と容量、最終使用、使用率が見られます。
- 地理/標高/建物の控えは、30日使っていない物と上限(既定 1GB・端末ごとに変えられます)を超えた分を自動で片付けます。「今すぐ整理」でいつでも片付けられます。
- 都市モードの建物(PLATEAU)も端末に控えるようになり、一度表示した街は電波が無くても出ます。
- 「永続化を要求」で、容量不足でもデータを消さないようブラウザに頼めます。

### 検索と位置の小さな改善
- 時間フィルタに「月の出」「月の入」が加わりました(並びは 日の出→月の出→GH[終]→GH[始]→月の入→日の入)。その日に月の出(入)が無い日は、その条件のフィルタは何も通しません。結果の「月の出時刻」「月の入時刻」が翌日の時刻の時は、24時を足した表記(例: 24:45:46)になりました。
- 観測点を地名・座標・地図・GPS・写真から置いた時の高さが 0m から 1.5m(人の目の高さ)になりました。Hom の既定(東京タワー 150m)と目的点は変わりません。
- 位置情報メニューに「写位」ボタン: 写真の位置情報(Exif)を観測点/目的点に入れます(写真は端末内で読むだけで送信・保存しません)。
- 宙の窓検索のコントロール: 「構図」「辻オフセット点」をラジオで選び、それぞれの「リセット」で 0 に戻せます。二本指で動かした構図がカメラの「リセット」で戻らない不具合を直しました。

### お知らせ
- My辻リストの CSV の列名「標高フィルタ」「標高OKフィルタ」「標高NGフィルタ」が「可視フィルタ」「可視OKフィルタ」「可視NGフィルタ」に変わりました。古いファイルもそのまま読み込めます。
- 利用規約に、本アプリの目的(街や自然環境において宙や空を楽しむこと)と、共有機能の適正な利用についての項を足しました。プライバシーポリシーに、端末の控え(地図・標高・建物・天気)の説明を足しました。
