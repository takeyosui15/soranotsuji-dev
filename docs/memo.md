# メモログ(宙の辻)

このファイルは、開発者のアイディアなどの今後作りたいものなどのメモの記録用です。

## 運用ルール
- 新しい項目は、下の「## 新しいメモ」の上部に順に追加して書いていく(iPhoneのメモから貼り付ける)。
- memo.mdに書いたものは、todo.mdの優先順位付きリストには直接入れず、Claudeがtodo.mdの「備忘録リスト(優先順位なし)」に1行ずつ追加する。
- アイディアの優先順位付きリストへの昇格は、依頼者が行う。
- todo.mdの備忘録リストへ移したものは、Claudeが `docs/memo-log/memo-done-YYYY-MM.md`(月ごと)へ原文を移す(第184から。memo.md を短く保ち iPhone へ貼り直しやすく。以前の「## 移動済」の節もそちらへ移した)。
- Claudeがmemo.mdを編集し終えたら、依頼者はmemo.mdの全文をiPhoneのメモへ貼り直す(memo.mdが正・iPhoneは写し。第144・依頼者提案)。
- 削除しても履歴はgitに残る(`git log -p -- docs/memo.md` / `git log -S'語' -- docs/memo.md`)。
- (2026-09-20 第143ラウンドで、依頼者提案の運用ルールに更新。旧ルール=完了したメモは削除・iPhoneのメモを全選択で貼り付け)
