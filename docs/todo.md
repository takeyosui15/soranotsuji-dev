# TODOリスト

プロジェクトのやることリスト、気になること、AIからの提案を一元管理します。
このファイルを開くだけで、今やるべきこと・気にかかっていることが一覧できます。

## 運用ルール
- 完了したら `[x]` にチェックを入れ、ラウンドの締めで Claude が「やることリスト > 実施済み(今月)」から `docs/todo-log/todo-done-YYYY-MM.md` へ移す(todo.md は「今」のための紙。短く保つ)。
- 不要になった項目は削除してOK(依頼者の判断でボツにした物は、理由ごと `docs/todo-log/todo-botsu.md` へ)。
- やることリストは「実施予定(優先順。上ほど先)/仕掛かり中/実施済み(今月)」の3段。備忘録は「まだ着手を決めていないアイデアの在庫」で優先順位は付けない(関連ごとにまとめる)。備忘録の物に着手を決めたら やることリスト へ移す(昇格は依頼者)。
- memo.md(依頼者のアイデア帳)の項目は、Claudeが「備忘録リスト（MEMO・優先順位なし）」へ1行ずつ移す(2026-09-20 第143)。Claudeがmemo.mdを編集し終えたら、依頼者がmemo.md全文をiPhoneのメモへ貼り直す(memo.mdが正・第144)。
- 棚卸し(全項目の済/未の判定と根拠の表)は Claude が作り(`docs/todo-log/todo-inventory-YYYY-MM-DD.md`・Koushi 記法)、依頼者が「判断」の列で仕分け、Claude が組み替える(2026-10-15 第180〜182)。次の棚卸しは「やることリスト」の最後の項目。
- AIは作業中に発生した相談で決めた方針について「開発者とAIとの協議内容と決定事項（DECISION）」に追記する
- AIは作業中に気づいた改善案を「AIからの提案（SUGGESTION）」に追記する
- AIは記憶が整理されたり次にハンドオフしても大丈夫なように「AIのやることリスト（TODO）」「AIの気になること（CONCERN）」に追記する(済みは同じく todo-done へ)
- バグを直したら、教訓を `knowledge/bugs.md` にも記録する
