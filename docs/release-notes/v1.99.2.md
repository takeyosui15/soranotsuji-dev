# 宙の辻 v1.99.2 リリースのお知らせ

宙の辻 v1.99.2 をリリースしました。前回 (v1.98.0) からの変更をまとめてお届けします。主な内容は、電波の無い所でも宙の辻を開けるようにしたこと (オフライン)、端末に控えたデータの管理、時間フィルタの「月の出」「月の入」、観測点の高さの見直し、写真の位置情報から観測点/目的点を置く「写位」ボタン、そして CSV の列名の変更です。

※ My辻リストの CSV と File取得の CSV の列名が変わります (5. をご覧ください。古いファイルはそのまま読み込めます)。
※ 観測点を地名・座標・地図・GPS・写真から置いた時の高さが 0m から 1.5m (人の目の高さ) になりました。辻検索や可視判定の結果が、ごくわずかに変わることがあります (4. をご覧ください)。
※ 開発中の機能 (可視マップ) は、今回のリリースにも含まれていません。

## 1. 電波の無い所でも開けるようになりました (オフライン)

一度開いておけば、電波の無い所でも宙の辻を開き直せます。山の上や谷の中でも、麓で開いておいた宙の辻をそのまま使えます。

- 開く時はいつも最新を取りに行き、取れない時だけ端末の控えを使います。控えから開いた時は、画面の下の版の横に「(オフライン表示)」が出ます。通信が切れている間は「(通信なし)」、開いている間に新しい版が届いた時は「(新しい版あり)」が出ます (再読み込みすると新しい版になります。作業中の画面を勝手に読み直すことはありません)。
- 新しい版は、全部そろって確かめてから入れ替わります。途中で電波が切れても、古い版のまま動きます。
- 地図・標高・建物 (PLATEAU) は、一度表示した範囲だけ使えます。Google ドライブ同期・地名検索・天気の取得には通信が要ります (Google Plus Code の変換は通信なしでできます)。
- **準備**: ①電波のある所で宙の辻を一度開いて少し待ちます (バックアップ/インポートメニューの「本体の控え」に件数・版・最終更新日時が出れば完了)。②使う予定の範囲の地図を一度表示し、標高グラフや辻検索を一度動かしておきます。
- **iPhone/iPad**: Safari も Chrome も同じ仕組み (WebKit) で、7日ほど宙の辻を開かないとブラウザが控えを消すことがあります。「ホーム画面に追加」(共有ボタン→ホーム画面に追加) した宙の辻は消されません。ホーム画面の宙の辻とブラウザのタブの宙の辻はデータの入れ物が別なので、My観測点などはバックアップ/インポートか Google ドライブ同期で移してください。
- **Android**: Chrome のメニューから「ホーム画面に追加」すると、容量不足でも消されにくくなります。バックアップ/インポートメニューの「永続化を要求」も同じ目的のボタンです。
- 使い方の詳細は、アプリ内のヘルプ「オフライン時のデータについて」と、よくあるお問い合わせの「電波の無い所でも使えますか」をご覧ください。

## 2. 端末のデータの管理

バックアップ/インポートメニューに「端末のデータ」の欄ができました。

- 全体 (ブラウザの見積もり)・永続 (はい/いいえ)・前回の整理・設定 (登録内容)・地理タイル・標高タイル・建物 (PLATEAU)・天気の控え・本体の控えの件数と容量、最終更新日時、最終使用、使用率が見られます。
- 地理/標高/建物の控えは、30日使っていない物と、上限 (既定 1GB) の9割を超えた分 (古い順に8割まで) を自動で片付けます (起動の少し後と画面に戻った時に1日1回。「今すぐ整理」でいつでも)。天気の控えは2時間を過ぎた物を片付けます。
- 各行の「上限 (MB)」はこの端末だけの設定です (バックアップや Google ドライブ同期には乗りません)。空欄にすると既定に戻ります。
- 都市モードの建物 (PLATEAU) も端末に控えるようになり、一度表示した街は電波が無くても出ます。「建物タイルを全削除」で空にできます。
- 「永続化を要求」で、容量不足でもデータを消さないようブラウザに頼めます (許可するかはブラウザの判断です)。
- 「本体の控えを削除」で、オフライン用の本体の控えを消せます (次に開く時に通信して作り直します)。

## 3. 検索の改善

- **時間フィルタに「月の出」「月の入」**: 辻検索・辻メッシュ検索・My辻検索の時間フィルタ (開始/終了時刻の基準) に「月の出」「月の入」が加わりました。並びは 日の出→月の出→GH[終]→GH[始]→月の入→日の入 です。その日に月の出 (入) が無い日は、その条件のフィルタは何も通しません。
- **月の出入り時刻の表記**: 結果リストと CSV の「月の出時刻」「月の入時刻」が翌日の時刻の時は、24時を足した表記 (例: 24:45:46) になりました (日時情報メニューと同じ表記です)。
- **宙の窓検索のコントロール**: 「構図」「辻オフセット点」をラジオボタンで選び、それぞれの「リセット」で 0 に戻せます。ラジオを切り替えても辻オフセット点は保たれます。二本指で動かした構図がカメラの「リセット」で戻らない不具合を直しました。
- **File取得**: 辻検索・辻メッシュ検索の File取得は、実行中にもう一度押すとキャンセルします (これまでは何度も押せて処理が重なることがありました)。辻メッシュ検索の File取得は、結果パネルに「検索→全画素の精細化→CSV生成」の進み具合が出ます。とても大きな結果 (数十万行) でも CSV を保存できるようにしました。

## 4. 位置の改善

- **観測点の高さ 1.5m**: 観測点を地名・座標・地図のダブルクリック・GPS・写真から置いた時の「高さ」が 0m から 1.5m (人の目の高さ) になりました。Hom の既定 (東京タワー 150m) と目的点の高さ (0m) は変わりません。既に登録してある My観測点の高さも変わりません。
- **写位ボタン**: 位置情報メニューに「写位」(写真の位置) ボタンを足しました。写真の位置情報 (Exif) を、ラジオで選んでいる観測点/目的点に入れます (標高は緯度経度から取得)。写真は端末の中で読むだけで、送信も保存もしません。

## 5. CSV と結果リストの列名の変更 (お知らせ)

- My辻リストの CSV の列名「標高フィルタ」「標高OKフィルタ」「標高NGフィルタ」(55〜57列目) が「可視フィルタ」「可視OKフィルタ」「可視NGフィルタ」になりました。古い列名のファイルもそのまま読み込めます (読み込みは列の位置で行うため)。
- 辻検索・辻メッシュ検索・My辻検索の File取得の CSV と、画面の結果リストの列「標高グラフ」(可視判定の OK/NG/-) が「可視判定」になりました。表計算ソフトなどで列名を見て処理している場合だけ、新しい列名に合わせてください。

## 6. 利用規約・プライバシーポリシー・安全性

- 利用規約に、本アプリの目的 (街や自然環境において、宙 (そら) や空を楽しむこと) と、共有機能 (URL・Myセットなど) の適正な利用についての項を足しました。
- プライバシーポリシーに、端末の控え (地図・標高・建物・天気) の説明を足しました。控えはこの端末の中だけにあり、どこにも送られません。
- v1.98.0 のセキュリティ強化に続いて、アプリの作りをもう一度点検しました (取り込むデータの検査・通信先の許可リスト・端末の控えの扱い)。利用者の方にしていただくことはありません。

## 7. その他の修正

- Google ドライブ同期の「:自動更新」のチェックがオフにできない不具合を直しました (v1.98.1)。
- 写位ボタンの幅を、位置情報メニューの他のボタンと揃えました。
- 辻検索・辻メッシュ検索などの計算に使うワーカー (並列処理) の数を、端末の CPU 数より1つ少なくしました。画面の操作や端末の控えの片付けが、計算中でも滞りにくくなります。
- ホーム画面に追加した時のアイコン (192px・512px) を足しました。
- ヘルプに「オフライン時のデータについて」の節を作り、端末の控え・端末のデータ・オフラインでの利用方法をまとめました。
