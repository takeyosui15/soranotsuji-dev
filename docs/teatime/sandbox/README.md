# sandbox(熟成中の実験と道具)

1 ラウンドで作り切らず、複数ラウンドかけて育てる物の置き場(第195ラウンド・依頼者の提案)。
育ったら `ClaudeMederuU/tools/` へ昇格し、台帳(ClaudeMederuU/tools/README.md)に載せる。

## 決め

- ここにある物は宙の辻の配信物ではない(sw-precache・CSP・verify の対象外)。本体のコードを触らない。
- 外から取る物(衛星画像など)はリポジトリに置かない。取り方(コマンド)だけ README に書く。
- 1 つの実験に 1 フォルダ。README に「何をする物・使い方・限界・次の一手」を書く。
