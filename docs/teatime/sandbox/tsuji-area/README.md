# tsuji-area — 「辻エリア」を GPU で毎フレーム計算する試作

第196ラウンド(2026-10-24)。依頼者の案「辻ラインは線。現在日時の辻位置が地図上でパッと分かる『辻エリア』を、精度 ◎○△- で塗り分け、時刻スライダーでぬるぬる動かしたい。GPU を使うかもしれない」を、箱の中で試した。

## 何をする物

- 画面の全画素について「その地点に立った時、目的点(富士山)の方位・高度角と、その地点での太陽の方位・高度がどれだけ近いか」(角距離)を WebGL2 のフラグメントシェーダーで毎フレーム計算し、◎(±0.125°・赤枠だけ)・○(±0.25°・天体色)・△(±1°・濃い金)・-(許容範囲内・薄い金)で塗る。しきい値は本体の `_tmAccSymbol`/辻検索の記号と同じ。
- 太陽の方位・高度は観測点ごとに違う(100km 離れると 1° 近く変わる)ので、CPU で赤経・赤緯・グリニッジ視恒星時を 1 回求めて uniform で渡し、シェーダーの中で各画素の緯度経度から方位・高度を出す(Astronomy Engine は CPU 側)。
- 国土地理院の標高タイル(dem_png・zoom 10・約 125m/画素)で観測点の標高を読む。`?occl=1` で、観測点から目的点への視線を標高の上で歩き(既定 48 歩)、地形に遮られる画素は塗らない(丹沢の西側で帯が切れるのが見える)。
- 背景は国土地理院の標準地図タイル。目的点の印と凡例は 2D canvas で重ねる。

## 使い方(箱の中で)

1. タイルを取る: 目的点を含む zoom 10 のタイルを中心に 7×7 枚、`dem/dem_10_{x}_{y}.png`(dem_png)と `std/std_10_{x}_{y}.png`(std)。海は dem が 404 なので無視(0m)。`area_meta.json` に z/x0/y0/n と target を書く。
2. `vendor/astronomy.browser.min.js` を同じフォルダに置き、`python3 -m http.server 8102` で配る。
3. `node area.js 0`(遮り無し)/ `node area.js 1 48`(遮り有り・48 歩)。2026-10-24 16:00〜17:00 JST を 1 分刻みで 61 フレーム描いて時間を測り、16:20/16:40/17:00 の 3 枚を `out/` に書く。

## 結果(2026-10-24・箱の中=SwiftShader の CPU 描画)

| 条件 | 画素数 | 1 フレーム(中央値) |
|---|---|---|
| 遮り無し | 1792×1792=約 320 万 | 168ms |
| 遮り有り(48 歩) | 同上 | 168ms |

- 遮りの計算を足しても時間が増えないのは、帯の中(許容範囲内)の画素だけが視線を歩くから。
- SwiftShader は GPU の無い箱で CPU が GPU のふりをする物なので、この数字は上限の目安。本物の GPU(スマホ含む)では 2 桁速いと見込む(未実測。着手時にスマホで測る)。
- 絵: 16:40 JST、富士山での太陽は方位 253.3°・高度 3.2°。薄い金の帯が町田〜東京へ伸び、その中に濃い金(△)の芯。◎○は数画素の幅なので zoom 10 の絵では細い線(本体の地図ならズームで見える)。遮り有りでは丹沢の陰になる相模原より西が消える。

## 設計の結論(本体に入れる時のために)

- 時刻に依らない物(各画素の目的点への方位・高度角・遮りの有無)を先に 1 枚のテクスチャに焼いておけば、毎フレームの仕事は「太陽の方位・高度との比較」だけになる。1 分ずつの先読みも、辻メッシュの算法の GPU 化も要らない。
- 太陽は視差を無視できるが、月は観測点で最大約 1° の視差があるので、画素ごとに視差を補正する式(地心→測心)をシェーダーに入れる。
- MapLibre との統合は、カスタムレイヤー(地図の WebGL コンテキストに自分の描画を足す仕組み。v4 でも使える)か、canvas ソースで絵を貼る形。版上げは前提にならない。
- ◎の赤枠は「◎の内側は塗らず、◎の縁だけ赤」で下の地図が見える(依頼者案)。

## 限界と次の一手

- 標高は zoom 10 なので、観測点の標高が 125m 四方の平均。本体の辻メッシュと同じ標高タイル(zoom 14)にすると細かくなる。
- 大気差は目的点の高度角に地球の丸み(k=0.13)だけ。太陽の高度の大気差(地平線近くで 0.5°)は未反映。
- 次の一手: ①時刻に依らないテクスチャの事前計算 ②月の視差 ③MapLibre のカスタムレイヤーで本体の地図に重ねる ④スマホで実測。
