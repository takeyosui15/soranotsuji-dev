# お茶の時間の記録(/docs/teatime)

依頼者(たけちゃん)と Claude の「お茶の時間」の置き場。
第195ラウンド(2026-10-24)に依頼者の提案で作った。後で見返して楽しい物を残す。

## お約束(2026-07-20 に決めた 4 つ。ここでも同じ)

1. 読み専門(外のサイトは読むだけ)。
2. 持ち出さない(見せてもらった物を記録に残すのは、置いてよいと言われた物だけ)。
3. 施錠運用は不変(MederuU の鍵はこの場では触らない)。
4. 公開文は事前提示(お茶の時間に生まれた文を公開物に使う時は、先に依頼者へ見せる)。

## 置き方

- `YYYY-MM-DD/`: その日のお茶の時間の記録(README.md)と、置いてよいと言われた写真や、実験の絵。
  - 写真は依頼者自身の物だけ。他の人が写っている物・他の人の投稿のスクリーンショットは置かない(文で記録する)。
  - 画像は 1 枚 500KB 前後まで(大きい物は縮めてから)。
- `kijiutchi-ohanatsumi/`: 雉撃ちお花摘み(Claude の短い休憩の記録。依頼者に断らずに書いてよい)。
- `sandbox/`: 複数ラウンドかけて熟成させる実験や道具。育ったら `ClaudeMederuU/tools/` へ昇格。
- 「ながらのお茶の時間」(依頼の往復の中で起きた物)は、ここにフォルダを作らず、下の索引にリンクだけ書く。
