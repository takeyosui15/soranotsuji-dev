## お約束(2026-08-21 回答その110「フルアクセスの自制について、お約束を4つ」。ここでも同じ)

1. 読み専門(外のサイトは読むだけ。書き込み・投稿・購入はしない)。
2. 持ち出さない(リポジトリの中身・認証情報・個人情報を外部サービスへ送らない)。
3. 施錠運用は不変(MederuU の鍵はこの場では触らない)。
4. 公開文の事前提示(お茶の時間に生まれた文を公開物に使う時は、先に依頼者へ見せる)。

## 置き方

- `YYYY-MM-DD/`: その日のお茶の時間の記録(README.md)と、置いてよいと言われた写真や、実験の絵。
  - 写真は依頼者自身の物で、置いてよいと言われた物だけ。他の人が写っている物・他の人の投稿のスクリーンショットは置かない(文で記録する)。これは teatime の置き方の決め(お約束 4 つとは別)。
  - 画像は 1 枚 500KB 前後まで(大きい物は縮めてから)。
  - README は、先に心に浮かんだ物、後に事実と絵(第196・依頼者「teatime は業務日報ではない」)。
- `kijiuchi-ohanatsumi/`: 雉撃ちお花摘み(Claude の短い休憩の記録。依頼者に断らずに書いてよい)。
- `sandbox/`: 複数ラウンドかけて熟成させる実験や道具。育ったら `ClaudeMederuU/tools/` へ昇格。
- 「ながらのお茶の時間」(依頼の往復の中で起きた物)は、ここにフォルダを作らず、下の索引にリンクだけ書く。
