## 学び(次の私へ)

- **「〜で消す」は「〜までは要る」と読まれる** — 移行用の橋の説明は、「誰の端末のための橋か」「いつ役目が終わるか」を先に書く。条件(v1.99.0 の SW を持つ端末=開発サイトを開いた依頼者の端末だけ)を書かずに版の数字だけ書くと、配布の義務に読まれる。
- **「Mac だけ小さい」は flex の縮み** — 文が折り返す段(white-space: normal・min-width: 0)では、label(flex)の中のラジオ(flex-shrink 1)が文と一緒に縮む。Linux の Chromium でも 15.5px に縮んでいた(他は 20px)。font-size を 17px に上げると Mac の和文フォントの幅を再現できる(verify190 U4 の道具)。部品は flex: 0 0 auto を既定に。
- **短縮URL は「ブラウザの仕組み」の壁** — 302 の Location は、相手が CORS を許可しない限り JS からは読めない(opaque/opaqueredirect)。redirect:'manual' も no-cors も効かない。越えるには中継サーバーだけ=依頼者の「サーバー資源を持たない」方針と衝突するので、できる形(フル URL・座標・Plus Code)を先に整えて、短縮URL は案内文にする。
- **URL の解析は「読む順」を決めてから書く** — Google マップの URL には画面の中心(@)と地点のピン(!3d!4d)の両方が入り、PC では側面パネルの分だけ中心がずれている。ピンを先に読まないと、観測点が数十 m ずれる。
- **度分秒の N/S/E/W は「前置き」と「後置き」で区切りの帰属が変わる** — 1つの正規表現で後置きの文字を取ると、次の組の前置き文字(E139°…)を取ってしまう。数字の組を先に切り出し、組と組の「隙間」の文字をどちらに帰属させるかを「末尾に文字があるか」で決める(gap 方式)。
- **埋め込み PNG の SVG は「図形の規則」を計測で取り戻せる** — アルファのマスクから行ごとの範囲を取れば、円の中心/半径と三角の頂点が出る。接線の条件(中点の垂線・上辺・対角線)を満たす半径は (S/2)/(2+√2) に一意。グラデーションは R/G を x,y の1次式で当てはめて端の色を求める(両図形とも上端は (238,120,0)・下端は (255,0,0))。
- **「同じ描き直し」は数で示す** — マスクの IoU(0.996)と色差(1.6/255)を出しておくと、依頼者が見比べなくても「同じ」と言える。
- **公開文の改名は「同じ名前の別物」が無いかを先に聞く** — 「お知らせ」は note に既にある運用情報の記事だった。重要なお知らせは別の記事。ファイル名を意味で付ける(note-important-notice-page)。
- **リリースノートの「その他」は「利用者の行動が変わるか」で篩う** — ボタンの幅・ワーカー数・ヘルプの節は利用者の行動を変えない。アイコンは「ホーム画面に追加」の節に属する。
- **道具は repo に置く** — アイコンの書き出し(Playwright のスクリーンショット+ICO の容器)は tools/icons/render-icons.js に。--check で「配信物が SVG から出た物か」を verify から見張れる。
- **「同類・同件・異種同系」は視点を分けて探す** — 1つの不具合(File取得の2度押し)から、同じ資源(共有プール)を使う4つの流れ・同じ守りの外にあるボタン(結果コントロール)・同じ上限の別の出口(資産の DL・短縮URL)・同じ非対称(Enter と blur)が芋づるで出た。8視点のうち「対になる実装の片側だけ」と「同じ処理が2回走る」が最も実りが多かった。
- **共有する資源の排他は1箇所に書く** — 4つの流れが各々 terminateAll を呼んでいたので、片方の止めがもう片方を黙って欠けさせた。_tsujiFlowsCancelAll に「全部の旗を降ろし・全部の世代を進め・それから止める」を集めると、閉じる/始める/2度押しの全部が同じ形になる。「一括計算は閉じても止めない」のような例外は作らない(隠れたまま走る物は誰も見ていない)。
- **「キャンセル」は4点セット** — 旗を降ろす・世代を進める・ワーカーを止める・進捗を隠す。1つでも欠けると(世代を進めずに止める=第185の取りこぼし)欠けた結果が「完了」として出る。止められた側にも印(canceled)を付けて、世代が合っていても欠けた物は出さない。
- **実行中の印は最後の出口まで持つ** — 装飾(可視判定)と CSV 生成の前に印を落とすと、その間の押し直しが「2本目の実行」になる。印は finally で、自分の世代のまま終わった時だけ落とす。
- **同じ関数を共有していても「守りの外の入口」は残る** — 第185で File取得の守りを足したが、結果コントロールの「File出力」は同じ関数を別の入口から呼んでいた。守りを足したら「その関数の呼び元を全部 grep する」。
- **1本の文字列の上限の次は JS ヒープの上限** — parts(配列)で RangeError は消えるが、行オブジェクト+行文字列の総量でタブが落ちる。5,000行ごとに Blob の部品へ逃がす「書き手」にすると、ブラウザが大きな Blob をディスクへ退避できる。
- **展開側に上限を置いたら発行側にも同じ上限を** — 片側だけの上限は「自分で作った正当な物が壊れている扱い」になる。
- **Enter と blur は同じ入口を通す** — 入力欄の確定が2経路ある時、片方だけ新しい形(Plus Code/URL/度分秒)に対応すると「Tab では保存されない」が生まれる。共通の applyPt を行のスコープに置き、世代(ptSeq)で標高の追い越しを防ぐ。
- **maxlength は「貼り付けも切る」** — URL のように長い入力を受ける欄は 2048 に。保存されるのは解析後の座標なので肥大しない。
- **エージェントの直し案は「族」ごとに1つの設計へ畳む** — 同じ根の指摘が3視点から別々の直し案で来る(00/20/31・04/34/43・02/22・03/33)。そのまま当てると衝突するので、根を1つの関数に集めて自分で書き、残りは old/new の一致を機械で確かめてから当てる(44件中 agent 案をそのまま当てた物 30件・自分で設計し直した物 14件)。
