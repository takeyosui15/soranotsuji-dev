# Koushi Preview 動作確認サンプル

このファイルをVSCodeで開き、プレビュー(Cmd+Shift+V)で下の3つが**罫線つきの表**として
描かれれば、拡張は正しく動いています(コードフェンスのままの文字列が見えたら未インストール)。

## 1. マトリックスCL(組み合わせ表の例)

```koushi
- t:1.
  - r:1:h.
    - c:1. 検索
    - c:2. 曜日フィルタ
    - c:3. 精度フィルタ
    - c:4. 標高フィルタ
  - r:2.
    - c:1. 辻検索
    - c:2:c. ○
    - c:3:c. ○
    - c:4:c. ○
  - r:3.
    - c:1. 辻メッシュ検索
    - c:2:c. ○
    - c:3:c. 読専固定
    - c:4:c. ○
  - r:4.
    - c:1. My辻検索
    - c:2:c. 行ごと
    - c:3:c. ○
    - c:4:c. 行ごと
```

## 2. 状態遷移表(結合セルの例)

```koushi
- t:1.
  - r:1:h.
    - c:1. 状態
    - c:2. 検索実行
    - c:3. フィルタ変更
    - c:4. リセット
  - r:2.
    - c:1. 結果なし
    - c:2. 結果あり
    - c:3:c. -
    - c:4. 結果なし
  - r:3.
    - c:1. 結果あり
    - c:2. 結果あり(再検索)
    - c:3. 結果あり(再導出)
    - c:4. 結果なし
```

## 3. チェックリスト(input要素の例)

```koushi
- t:1.
  - r:1:h.
    - c:1. 済
    - c:2. 確認項目
  - r:2.
    - c:1:c.
      - chb:on.
    - c:2. ハーネス構築
  - r:3.
    - c:1:c.
      - chb.
    - c:2. 回帰実行
```
